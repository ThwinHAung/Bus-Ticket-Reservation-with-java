# Bus Ticket Reservation System (Java GUI + MySQL)

This repository contains a **mini Java GUI application** for a **Bus Ticket Reservation System**, developed using **Java** and **MySQL**.  
The project was created as the **final project for the Java course (CSX3002)** at **Assumption University of Thailand**.

---

## Project Overview

- Desktop-based Java application
- Graphical User Interface (GUI)
- MySQL database integration
- Basic bus ticket reservation workflow
- Academic project for Java course assessment

---

## Features

- User-friendly GUI for ticket reservation
- View available bus routes and schedules
- Book bus tickets
- Store and retrieve reservation data from MySQL
- Simple database-driven operations (CRUD)

---

## Technology Stack

- **Java**
- **Java GUI** (Swing / JavaFX, depending on implementation)
- **MySQL**
- JDBC for database connectivity

---

## System Functionality

- Connects to a MySQL database
- Retrieves bus and ticket information
- Allows users to reserve tickets through the GUI
- Stores reservation records persistently
